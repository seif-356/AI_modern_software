This directory contains function-level adaptations of Python submissions from the [ConDefects dataset](https://github.com/appmlk/ConDefects), curated by Yonghao Wu, Zheng Li, Jie M. Zhang and Yong Liu from public AtCoder submissions. Each record identifies the original task, submission ID, source snapshot and source path. The transformed programs retain the dataset's [CC BY-SA 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).

The preparation script wraps each contest program in a function that consumes a string and captures its standard output. It retains one eligible submission per task and partitions the public input/output examples in the English AtCoder task statement. Each record contains the URL of that statement. These examples have separate AtCoder provenance. The sample includes no problem-statement prose. The manifest records the exact task difficulty and file digest.
